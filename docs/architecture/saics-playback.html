How a jump is played

Every bar, the walk decides one bar ahead whether to jump; the jump is handed over as a single instruction for the exact downbeat frame. The renderer, the only real-time thread, takes it a block ahead and fades between the two places over 30 ms, matched by correlation so the seam doesn't dip. The screen hears about it twice: early, so the hand can reach the record, and when it happens.
